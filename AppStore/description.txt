Uniloop — planned offline 3D momentum-racing game for Windows, Android, and iOS phones and tablets.

This is pre-release planning copy, not a claim that a playable build is available. The intended game lets players ride an original single-wheel racer across sculpted courses, balancing momentum through banked turns, jumps and clean landings.

Planned features: three original courses, time trials and local medals, optional stunt lines and best-run ghost replay, touch controls on phones/tablets plus keyboard/gamepad on desktop, adaptive menus, local save records with JSON export/import, and no accounts, ads or trackers.

Store description will be revised against real shipped features before publication.
